# Customer Churn Analysis

## Project Overview
This project analyzes customer churn behavior for a telecom company using Excel, SQL, Python, and Power BI. The goal is to identify key factors driving churn and build a model that predicts which customers are likely to leave.

## Tools Used
- Excel
- MySQL
- Python (pandas, seaborn, scikit-learn)
- Power BI

## Workflow
1. Data cleaning in Excel
2. SQL queries for churn analysis
3. Python EDA and churn prediction model
4. Power BI dashboard for business insights

## Key Insights
- Overall churn rate: **26.54%**
- Month-to-month contracts have the highest churn.
- Customers using **electronic check** show the highest churn rate.
- New customers churn significantly more than long-term customers.
- Higher monthly charges are associated with higher churn probability.

## Model Results
A logistic regression model achieved **~81% accuracy** in predicting churn.

Top factors influencing churn:
- Contract type
- Internet service
- Online security
- Tech support
- Customer tenure

## Business Recommendations
- Encourage long-term contracts to reduce churn.
- Provide incentives for new customers to stay beyond the first year.
- Review pricing strategies for high-charge plans.
